# moncon
Simple Monitor Control App

Available functions:
- brightness up
- brightness down
- turn off display
- turn on display

## Setup
1. Download and unzip [latest release](https://github.com/r3poo/moncon/releases/latest)
2. Edit `.env` file with prefered hotkeys

## Running
1. Run `moncon.exe`
2. Close app from system tray

## Build from Source
1. Install dependencies in `requirements.txt`
2. Run pyinstaller build with `pyinstaller -D --noconsole moncon.py`

## Compatibility
No dependencies\
Only tested working on Wiindows 11
